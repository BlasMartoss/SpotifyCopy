# 🎧 Spotify Copy

Este proyecto es una copia inspirada en Spotify, donde puedes reproducir canciones de las *playlists* creadas.

## ✨ Características Principales

* **🎶 Reproducción de Playlists:** Reproducción de *playlists* con canciones, tal como en Spotify.
* **🎨 Diseño Atractivo:** Interfaz de usuario diseñada para una experiencia de calidad.
* **🎤 Información de Artistas:** Detalles relevantes sobre los artistas.

## 🚀 Tecnologías Utilizadas

Este proyecto ha sido desarrollado utilizando las siguientes tecnologías:

* **⚛️ React:** Para construir interfaces de usuario dinámicas y reactivas.
* **💨 Tailwind CSS:** Para darle vida al proyecto.
