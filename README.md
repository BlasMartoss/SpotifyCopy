# Spotify Copy

Este proyecto es una copia inspirada en Spotify

## ✨ Características Principales

* **🎶 Reproducción de Playlists:** Disfruta de la reproducción de tus playlists favoritas, tal como en Spotify.
* **🎨 Diseño Atractivo:** Interfaz de usuario cuidadosamente diseñada para una experiencia de calidad
* **🎤 Información de Artistas:** Explora detalles relevantes sobre los artistas.
